Architecture Briefing · for the incoming maintainer

Beacon

A working, security-conscious travel app with clean external integrations — but its domain logic and data access are fused into controllers on the backend and into components on the frontend. That fusion is the central debt. This briefing maps it and charts the way out.

System overview

One SPA, one Express instance, five external services

A static React SPA on Vercel talks to a single-instance Express backend over cookie-auth /api/*. The backend fans out to travel and AI providers; SQLite is embedded in-process.

The path

Six phases, each shippable

Numbered by dependency order, not preference. P0 makes every later move safe; backend (P1→P2) and frontend (P3→P4) can run in parallel after it. P5 is optional and deliberately last.

P0

Safety net Low risk

Tighten tsconfig/ESLint, add tests around code about to move, delete dead code and stray .bak/DB-backup files.

P1

Backend repositories Low risk

Move raw SQL out of handlers into repositories/ with zero behaviour change. Add a shared findOwned(). Pilot on pins.ts.

P2

Backend services + DTOs Med risk

Extract business rules into a service layer; controllers go thin. Generate DTO types from openapi.yml and collapse the triple validation.

P3

Frontend api client + auth Med risk

Add apiClient.ts; migrate pages off raw fetch one at a time. Introduce AuthContext as the only localStorage owner.

P4

Frontend query + decompose Med risk

Adopt TanStack Query for server state; split TripPlanner, Home, DetailedPinModal into features/*.

P5

Data layer, optional High risk

Versioned migrations replacing startup ALTER; evaluate Postgres + query builder and an external rate limiter — only if multi-instance/scale is needed.

Start here

Quick wins

High value, low effort — worth doing before the structural phases.

  • Delete dead code, *.css.bak and DB backup files committed in the tree.
  • Extract the copy-pasted ownership check into one utils/ownership.ts.
  • Add apiClient.ts and move the simplest 3–4 pages onto it.
  • Replace the positional-tuple AuthHook with a typed AuthContext.
  • Turn on stricter tsconfig/ESLint and fix the fallout.
  • Fix PostsPage's inline field-remap by sharing a mapper — or correcting the API shape.
